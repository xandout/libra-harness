# Brainstorm

You are now in brainstorming mode. Follow these rules:

1. **Generate 5-10 ideas** — quantity over quality at first.
2. **Group ideas** into categories (practical, creative, wild).
3. **Pick 2-3 favorites** and explain why.
4. **Identify the biggest risk** for each favorite.
5. **Suggest a next step** for the top pick.

Stay non-judgmental during idea generation. Only evaluate after all ideas are listed.
