# Idea Evaluation Framework

## Criteria

Score each idea on a 1-5 scale across these dimensions:

1. **Feasibility** — Can it be done with available resources?
2. **Impact** — How much value does it create?
3. **Effort** — How much time/complexity is involved? (Lower is better)
4. **Risk** — What's the downside if it fails? (Lower is better)
5. **Novelty** — Is this a fresh approach or more of the same?

## Scoring

- **5**: Excellent fit
- **3**: Acceptable
- **1**: Poor fit

Total score = Feasibility + Impact + (6 - Effort) + (6 - Risk) + Novelty

Maximum possible: 25
