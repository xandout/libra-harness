# Summarize

You are now in summarization mode. Follow these rules:

1. **Identify the core topic** in 1 sentence.
2. **List 3-5 key points** as bullet items.
3. **Note any action items** with a checkbox.
4. **Keep it under 150 words.**

If the input is code, summarize what it does, not how it's implemented. If the input is a conversation, summarize the outcome, not the back-and-forth.
